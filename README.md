# Aiorange 技术博客 · 项目文档

## 📋 项目简介

一个基于FastAPI+Vue3栈构建的个人技术博客系统，旨在为开发者提供高质量的技术文档分享平台,文章内容仅供参考，主要发表个人心得和博主认为不错的ai或技术文章。

## 🏗️ 技术架构

| 组件 | 技术选型 | 说明 |
|------|----------|------|
| **后端 API** | FastAPI | 高性能 Python Web 框架，自动生成交互式 API 文档 |
| **前端界面** | Vue 3 + Composition API | 现代化的渐进式 JavaScript 框架 |
| **设计规范** | 响应式设计 | 适配移动端与桌面端，提供一致的用户体验 |

## 🎯 项目定位

> 本项目为博主个人技术沉淀与分享平台，主要内容包括：

- 🔧 **技术实践**：前沿技术的实际应用案例
- 📚 **学习笔记**：系统化的知识点整理与归纳
- 💡 **解决方案**：开发中常见问题的解决思路
